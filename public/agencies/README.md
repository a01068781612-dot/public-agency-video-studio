# 기관 로고/상징 워터마크

`홍보 타겟 기관`을 지정한 영상의 우측 상단에 표시되는 워터마크 이미지를 여기 둔다.

## 파일을 안 넣어도 된다

로고 파일이 없으면 **기관명 텍스트 배지**로 나간다. 워터마크가 통째로 사라지지 않는다.
(예전에는 파일이 있어야만 워터마크가 떠서, 기관을 골라도 화면에 아무 표시가 없었다.)

## 한 장이면 대부분 커버된다 — `gov.png`

2016년 3월 정부상징체계 통합으로 **대부분의 중앙행정기관은 부처별 CI 를 없애고 동일한
태극 상징 + 기관명**을 쓴다. 그래서 부처마다 로고를 모을 필요가 없고, 통합 정부상징
한 장을 `gov.png` 로 넣어두면 그 기관들 전부에 적용된다.

## 고유 상징을 유지하는 기관만 따로

통합에서 제외되어 고유 상징을 쓰는 기관은 `<기관 id>.png` 로 개별 파일을 둔다
(`src/lib/agency.ts` 에서 `ownSymbol: true` 로 표시된 곳):

| 기관 | 파일명 |
| --- | --- |
| 국방부 | `mnd.png` |
| 검찰청 | `spo.png` |
| 경찰청 | `police.png` |
| 소방청 | `nfa.png` |
| 해양경찰청 | `kcg.png` |

## 이미지 규격

- 정사각형에 가까운 PNG, 배경 투명 권장 (워터마크가 원형으로 잘려 표시됨)
- 최소 80×80px 이상 (표시 크기는 40×40)

## 어디서 받나

각 기관 홈페이지의 "기관 소개 → 상징/CI" 또는 행정안전부 정부상징 안내 페이지에서
내려받는다. 정부상징은 공공누리 이용 조건을 따르므로 사용 전 조건을 확인할 것.
